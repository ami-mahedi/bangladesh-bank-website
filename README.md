## 📌 Project Overview

**Bangladesh Bank Website** is a front-end website recreation inspired by the official website of Bangladesh Bank, the central bank of Bangladesh.

This project was developed to demonstrate practical skills in **HTML, CSS, and JavaScript** as part of the **Web Design & Development course assessment under the ILO Project / CBT training program**.

The project focuses on recreating a structured banking website interface with navigation menus, financial information sections, news areas, and contact information.

## ✨ Key Features

- 🏛️ **Banking Website Interface** — A structured layout inspired by the Bangladesh Bank website.
- 🧭 **Navigation Menu** — Organized sections for navigating website content.
- 📰 **Recent News Section** — A dedicated area for news and updates.
- 📊 **Policy Rates** — A section displaying sample policy-rate information.
- 🏦 **Reserve Ratios** — A structured presentation of reserve-ratio information.
- 💱 **Inter-Bank Exchange Rate** — A sample exchange-rate information section.
- 🔐 **ICT Security Alerts** — A dedicated area for security advisories.
- 📞 **Contact Information** — Contact details and useful links.
- 📱 **Responsive Layout** — Designed with attention to different screen sizes.
- ⚡ **Interactive Elements** — JavaScript-powered interface elements where implemented.

## 🚀 Run the Project Locally

You can run this project on your own computer without installing a framework or package manager.

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- Git (optional, for cloning the repository)

### 1. Clone the repository

```bash
git clone https://github.com/ami-mahedi/bangladesh-bank-website.git
```

### 2. Open the project folder

```bash
cd bangladesh-bank-website
```

### 3. Launch the website

Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the **Live Server** extension.
